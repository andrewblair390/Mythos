# Mythos

## What is Mythos?
Mythos is our first attempt at learning to mod Minecraft. Right now it is a small Greek Mythology themed mod that adds a few items. It is intended to add another dimension and slot right into the vanilla Minecraft experience and become sort of a "vanilla plus" experience.

## How to play?
Currently, this isn't playable without cloning the reop yourself, but in the current state I wouldn't recommend it. Check back in a few weeks
